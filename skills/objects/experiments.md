# Type skill — experiments

Read when creating or editing `EXP_*`. The folder `objects/experiments/` is created on the first create.

- One protocol, one ID. Point `run_dir` at `experiments/EXP_######/` for artifacts (that run dir is created when the run happens, not by the template).
- Status: `draft` → `planned` → `running` → `done` | `aborted`.
- Link `hypotheses` and, when finished, `results`.
- Parent path: `{slug}/objects/experiments`.
