# Type skill — claims

Read when creating or editing `CL_*`. The folder `objects/claims/` is created on the first create.

- Unverified until an experiment/result supports it. Not a result object.
- Status: `draft` → `asserted` → `accepted` | `retracted`.
- `accepted` without `links.results` or `links.experiments` is a completeness warning.
- Parent path: `{slug}/objects/claims`.
