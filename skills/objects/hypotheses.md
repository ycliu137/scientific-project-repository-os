# Type skill — hypotheses

Read when creating or editing `H_*`. The folder `objects/hypotheses/` is created on the first `project_api create --type hypothesis`.

- Must be falsifiable; link planned/actual `EXP_*` when tested.
- Status: `draft` → `open` | `active` → `tested` | `abandoned`.
- Parent path: `{slug}/objects/hypotheses` (`slug` from `os.yaml`).
