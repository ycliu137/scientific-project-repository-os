# clean_academic

Generalized from RegVelo / CellProphet journal-club Beamer theme
(`aspectratio=169`, primary `#1B4965`, accent `#CA6702`, `\sectionslide`, `\slidefig`).

Short bottom citations: `\slidecite{Lastname et al., J Abbrev YYYY}` (dark red;
default bottom-left, clear of page numbers). See `skills/slides.md`.

Use for **project progress** decks (background → progress → results → outlook).
